# task 02／03 简要验收指南

当前状态：开发与自动化验证完成，**真实 Obsidian 验收待你执行**。本次未代你操作宿主。

## 开始

1. 本插件三个构建文件已备份后更新；在设置中关闭再开启 **Selection Toolbar**，加载本次构建（不要重置 vault）。
2. 打开 [[01-菜单试用]] 与 [[02-原生对照]]：两份初始正文相同。正文修改只在这些新样例中进行；需要重复时撤销到原文，或自行复制样例。
3. 分别在 **实时预览** 和 **源码模式** 测试。先在笔记较靠上的行操作；最终窗口边缘避让、内部滚动属于 task 04，本轮未完成。
4. 不选中文字，把光标放在待操作行的指定列。插件和原生对照必须使用相同原文、相同源码行列，不能一边在行首、一边在行中。

## task 02：菜单与原生行为

- [ ] 清单是 16 项，顺序如下；每项有图标，只有三处分组线，没有行内说明或插件二级参数面板：
  - 文本、标题 1～6
  - 项目符号列表、有序列表、待办事项
  - 代码、引用、标注、公式区块
  - 表格、分隔线
- [ ] 在二级标题、普通无序／有序列表、未完成和已完成任务行打开，核对格式勾号。勾号与键盘高亮是两回事；任务勾号不表示完成状态。“文本”表示无标题，不是互斥块类型，可能与列表等格式同时勾选；表格、分隔线不加格式勾号。
- [ ] 对每项操作，在“菜单试用”选择插件操作，在“原生对照”通过 Obsidian 自带右键菜单或对应命令执行；比较 Markdown、执行后光标／选区、焦点及撤销／重做。宿主没有改动内容时，不要求新增历史记录。
- [ ] 原生对照输入至少覆盖：空行、普通正文行首／行中、已有标题、列表、引用、标注正文。可撤销后逐项重复，不用改已有笔记。

### 四个重点例子

| 输入与光标 | 操作 | 应核对的原生语义 |
| --- | --- | --- |
| `正文内容` 第 0 列，再恢复原文试第 2 列 | 标注 | 行首／行中结果不同，保留原生占位内容及 `NOTE` 选区，不自动移到行首 |
| `## 已有二级标题`、普通列表行 | 文本 | 移除标题，不把列表等一律清成普通段落 |
| 未完成／已完成任务行 | 待办事项 | 切换任务完成状态，不是幂等“设为待办” |
| `正文内容` 第 2 列 | 分隔线 | 光标处插入，可能拆句；不固定追加到整行后 |

代码、公式区块、表格也要对照宿主输出与新光标，尤其不要按 Notion 整块转换的预期判断。

## task 03：入口、搜索和键盘

- [ ] 点击加号，或命令面板运行 **Selection Toolbar: 打开插入菜单**：搜索框立即获得焦点，正文和光标未变；插件没有默认快捷键。
- [ ] 搜索 `正文`／`普通段落`、`待办`／`todo`、`标注`／`callout`、`标题`／`heading`、`table`：出现对应结果；大小写与首尾空格不影响匹配，中文输入法输入不泄漏到正文。
- [ ] 空搜索及每次新搜索默认高亮首个可用项；↑／↓切换，Enter 执行一次并关闭，保留宿主新光标／选区。
- [ ] 搜索 `no-such-action`：显示“没有匹配的操作”，Enter 不修改内容。禁用项若出现仍可搜索到、置灰，点击和 Enter 不执行；不要故意进入排除区域来制造禁用项。
- [ ] Esc 取消并回到原光标；点击外部不抢焦点。关闭重开清空搜索、旧高亮和滚动位置。
- [ ] 选中文字时、[[03-排除区域]] 的代码／公式围栏及内部、表格、顶部属性区域、阅读模式，不显示加号，也不能通过命令打开。
- [ ] 搜索中修改来源正文、移动光标或关闭该编辑器，旧菜单不能继续执行；停用插件后没有残留菜单、行提示或可用入口。
