## 4. 关闭与重开

- Esc 关闭工具栏；打开色板时先关色板、再关工具栏。
- 外部点击、开始输入、实际滚动会关闭，不应过一会自动重开。
- 保存、关闭笔记再打开，重复单击和内部拖选。
- 停用插件后仍使用标准 HTML 显示；本次没有修改存储格式。

## 范围与反馈

不承诺始终隐藏标签或直接逐字放光标；复杂手写 HTML、实体、跨格式块选择等不保证桥接。背景原生六色尚未改造，本次仍是既有背景实现。

请反馈：是否不弹出、是否闪退、是否改错文字；记录样例、实时预览/源码模式、主题和分栏情况。
