## task 04：定位、避让与滚动

- [ ] 长源码行自动折行：光标在首行／末行文字中移动，加号仍对齐该源码行第一个视觉行。菜单提示覆盖这一源码行的折行部分，不扩到下一源码行。
- [ ] 手动换行和多级列表：加号跟随实际源码行，横向位置固定，不随列表缩进变化。
- [ ] 开启行号（由你自行选择）、展开／折叠标题，检查加号不遮住行号、折叠箭头、列表符号或正文；按钮可点击，正文可拖选。
- [ ] 反复切换单光标／文字选区，再缩窄窗格：加号显隐不挤动正文，窄窗仍可输入与选择。
- [ ] 在窗口上／下／左／右边缘附近打开菜单：菜单不越出所属窗口，空间不足时向上／向左避让，不为了菜单滚动笔记。分栏和独立窗口也各试一次。
- [ ] 空搜索显示完整 16 项：列表内部可滚动，搜索框留在顶部；连续按方向键到末尾，当前项自动进入列表视口，正文不跟着滚动。
- [ ] 菜单打开时缓慢滚动笔记：目标仍可见则菜单跟随；整条源码行离开可视区域则关闭并清除提示，不抢回焦点。超长折行仅首个视觉行滚出时，加号不会浮到其他区域，菜单可继续对应仍可见的源码行。
- [ ] 调整窗口大小，菜单重新适应窗口。检查默认浅色、默认深色及至少一个已安装的额外主题；记录实际测试过的主题，不把未测主题勾为通过。

## task 05：退出与来源隔离

在 A 打开菜单，分别做下列操作；每次操作前重新打开菜单：

- [ ] 输入搜索、使用方向键、在菜单内移动焦点：菜单不误关闭，搜索不进入正文。
- [ ] 点击正文移动光标或修改正文：原菜单关闭，不继续作用于旧位置。
- [ ] 切换到 B、其他窗格、同一窗格的另一笔记或阅读模式：原菜单立即关闭；返回 A 不自动重开。
- [ ] 将 B 在 Obsidian 独立窗口打开并切换过去，再切换到其他应用（例如 Alt+Tab）：原菜单关闭、无多个悬挂菜单、无抢焦点；分别记录两个真实切换结果。
- [ ] A／B 轮流打开菜单并执行操作：只修改当前来源，另一篇笔记不变。切走或关闭 A 后，不能继续执行 A 的旧菜单。
- [ ] Esc：回到 A 原光标，无内容变化；外部点击：焦点留在你点的位置。
- [ ] 选择标题、标注或其他操作：只执行一次，保留原生结果及新光标／选区；撤销／重做仍按原生行为，不恢复旧快照、不弹额外通知。
- [ ] 菜单打开时关闭来源笔记、关闭其独立窗口，或停用插件：没有遗留菜单、行提示或仍可用的旧入口。重新启用插件后可以手动打开新菜单。
- [ ] 选中文字时加号隐藏；原文字工具栏的加粗／高亮仍可用。取消文字选区后可重新打开加号菜单，两者不串扰。
