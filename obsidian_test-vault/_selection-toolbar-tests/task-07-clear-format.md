# Task 07：清除格式与十入口体验

本页为新增体验材料，不替代或覆盖旧页。请手动关闭再启用 Selection Toolbar，在桌面端实时预览中体验。

## 1. 十入口与连续操作

正文 选择这些文字 结束。

鼠标选中“选择这些文字”，核对单行入口顺序：文字颜色、背景颜色、加粗、斜体、下划线、清除格式、链接、删除线、行内代码、行内公式。连续叠加普通样式和颜色后点击清除格式：只剩普通文字，选区及工具栏仍可用；随后可转换代码。每次实际修改均可单次撤销。

## 2. 单项及混合清除

正文 加粗、斜体、删除线 与 code 结束。

正文 [网页说明](https://example.com) 与 [[_selection-toolbar-tests/task-06-link-exclusive|笔记说明]] 结束。

选择完整代码正文或完整链接正文（渲染态链接可从两侧空白起拖）后清除，只留下可见文字；也可选择整个混合片段清除。切穿代码／链接应禁用，不会擅自扩选。

## 3. HTML 整块与局部清除

正文 <span style="color: #d44c47"><u><strong>一二三四五</strong></u></span> 结束。

单击格式块可以清除整块；也可在渲染正文内部拖选“二三四”，松开后清除。允许源码展开，未选中的“一”“五”应保留颜色、下划线及加粗。一次撤销恢复完整原文。

正文 <span style="background-color: #fbf3db"><em>背景与斜体</em></span> 结束。

## 4. 公式与列表保留

正文 粗体 $x+1$ code 结束。

选择整个行内片段清除：粗体和代码标记消失，公式源码与渲染保留。取消公式仍使用公式按钮；仅选择公式内部片段不会被清除格式改写。

- 普通列表里的 **加粗** 与 `code`。

1. 有序列表里的 **加粗** 与 [链接](https://example.com)。

只选择列表项内部文字，清除不得改变列表结构。跨项或跨段落选择不弹出工具栏。

## 5. 链接预览切换及撤销

正文 <u><strong>链接预览示例</strong></u> 结束。

单击格式块，打开链接弹层：显示去格式预览，但正文未改。直接点击“清除格式”，弹层和预览应关闭，原选区实际清除格式；一次撤销恢复原始下划线及加粗。已有链接不能叠加普通格式，移除或清除链接后只留下普通文字。

## 6. 关闭与范围

在普通段落上检查：Esc 先关闭面板再关闭工具栏；点击外部、输入、实际滚动关闭；无滚动位移的通知不应误关。标题、引用、任务列表、表格、代码块和公式块不自动显示工具栏。

> 这一引用块中的文字不应触发工具栏。

- [ ] 这一任务项中的文字不应触发工具栏。
