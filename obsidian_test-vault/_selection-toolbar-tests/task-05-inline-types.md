# Task 05 代码与公式体验

普通文字` x+y` 可以分别转换为行内代码或行内公式。

已有代码 `x+y`，完整选中正文或连同反引号可取消；只选一部分不能套其他格式。

已有公式 $x+y$，编辑渲染由 Obsidian 接管；不能直接转换成代码。

冲突 **加粗文字**、<u>下划线文字</u>、<span style="color: #d44c47">彩色文字</span> 的代码/公式按钮应禁用，提示先清除格式。

特殊输入：一个未配对的 ` 反引号可以用较长代码分隔符安全保存。首尾空白、美元符号和尾部反斜杠等公式输入不能安全表达时拒绝。
