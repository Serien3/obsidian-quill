再次打开，输入 `https://example.com` 并确认。选中文字应只剩链接，不再带加粗／斜体／颜色／下划线等格式；工具栏中的其他格式按钮禁用。

笔记链接也一样：输入已有笔记完整路径 `_selection-toolbar-tests/html-selection-bridge.md`，应遵循 Obsidian 当前 Wiki 设置，使用去掉格式后的可见文字作为别名。

## 4. 无效输入与退出

输入空地址、`不存在.md` 或 `http://example.com`：应提示且不提交。退出弹层后原格式仍在。切换色板或其他格式操作也会先取消链接预览；插件停用不应留下预览或丢失正文。

代码、公式、图片、嵌入、切穿链接和复杂手写 HTML 仍受安全边界保护，不会为了创建链接而破坏结构。背景色仍保持现有十色 HTML 实现，原生背景高亮改造已取消。
