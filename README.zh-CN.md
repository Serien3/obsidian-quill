# Quill

简体中文 | [English](README.md)

**保持原生 Markdown，让写作更顺手。**

## Overview

Quill 为 Obsidian 提供便捷的文字格式与插入工具，减少查找命令的打断，让你专注于写作。

借鉴 Notion 便捷的操作体验，但不替换 Obsidian 原有编辑器。笔记始终是 Markdown 文件：不引入私有内容模型、不另造编辑器，停用插件后仍可阅读与编辑。

## Key Features

- **选区工具栏**：在实时预览中用鼠标选中文字，快捷使用加粗、斜体、删除线、行内代码、行内公式、清除格式，以及内部链接和外部链接。
- **原生高亮颜色**：通过 Obsidian 原生高亮能力，选择默认高亮或六种颜色。
- **下划线**：添加、取消或局部取消已有下划线，以标准 HTML `<u>` 标签保存；不支持的结构会禁用操作，避免局部修改内容。
- **行旁插入菜单**：点击当前行旁的 `+`，选择文本、一至六级标题、列表、待办事项、代码块、引用、标注、公式区块、表格和分隔线。
- **搜索与键盘操作**：使用中英文关键词搜索插入操作，方向键切换、Enter 执行、Escape 关闭。
- **保持原生编辑语义**：已有宿主能力的格式与插入操作交给 Obsidian 执行，不另设一套块转换规则或内容存储格式。

## Requirements

已在 **Windows 桌面版 Obsidian 1.15.0** 上测试。其他版本及平台尚未验证，目前不支持移动端。

## Installation

### 从源码构建

使用 **Node.js 22 或更高版本**，在仓库根目录执行：

```sh
npm ci
npm run build
```

插件构建文件输出到 `dist/`。

### 手动安装

1. 在你的 vault 中创建目录：

   ```text
   <vault>/.obsidian/plugins/quill/
   ```

2. 将 `dist/` 中的三个文件复制到该目录：
   - `main.js`
   - `manifest.json`
   - `styles.css`
3. 在 Obsidian 中打开 **设置 → 第三方插件**，按需启用第三方插件功能，然后启用 **Quill**。
4. 更新时先备份已有安装，只替换本插件这三个文件，再重新加载插件。

## Usage

### 为选中文字设置格式

1. 在 **实时预览** 模式下打开 Markdown 笔记。
2. 用鼠标选中文字，显示浮动工具栏。
3. 点击格式按钮、打开高亮颜色菜单，或插入链接。

点击工具栏外部或按 Escape 关闭工具栏；使用 Obsidian 原有的撤销／重做命令回退编辑。

下划线以 `<u>文字</u>` 保存。插件不为 HTML 内的 Markdown 增加自制渲染，其显示遵循 Obsidian 的原生行为。

### 插入内容或调整当前行

1. 将单一光标放在可编辑的正文行，不选中文字。
2. 点击行旁的 `+`。
3. 搜索操作，或使用 ↑ / ↓ 选择后按 Enter 执行。

也可以在命令面板中运行 **打开插入菜单**。插件不设置默认快捷键，可在 Obsidian 的快捷键设置中自行绑定。当前界面文案为中文，插入搜索支持中英文别名。

代码块、公式块、表格和属性等不支持的上下文不会显示行旁入口；不可用的菜单项会禁用。操作遵循 Obsidian 原生语义：例如“文本”移除标题格式，并非清空全部块样式；待办事项操作可能切换完成状态。
